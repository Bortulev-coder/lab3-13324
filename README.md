# lab3-13324

Лабораторная работа №3 по программированию. Вариант 13324. Java 17.

Бортулев Александр Сергеевич, группа O3143, ПРГРМ O26 1.1.

Программа моделирует встречу Пятницы с отцом. Действия меняют положение,
физическое состояние, настроение, знания персонажей, план ухода и ресурсы.
Текстовый вывод отражает эти изменения.

## Запуск

Требуется JDK 17 или новее; внешние библиотеки не нужны.

## Действия модели

- `Person.approach(boat)` устанавливает `Location.BY_BOAT` и сохраняет конкретную лодку.
  До подхода помощь её пассажиру недоступна.
- `Boat.board/leave` согласуют список пассажиров и положение человека.
  Одновременная посадка в две лодки запрещена.
- Методы `Friday.cry/laugh/dance/waveHands/hitHead/hitFace` расходуют силы
  и сохраняют выполненные выражения радости. Прыжок и выход изменяют положение.
- `Friday.explainRelationship` сохраняет `FamilyRelation` в знаниях Робинзона.
- `Robinson.adviseMassage(friday)` задаёт план `CareMethod.RUM`.
  При нехватке рома выбирается `DRY`; `performCare` действует по плану.
- `WorldObject.recordEvent` сохраняет `StoryEvent` со снимком состояния.
  Прямой вызов `StoryLog.event` сосредоточен в `StoryNarrator`.
