ЛАБОРАТОРНАЯ РАБОТА 3 — ВАРИАНТ 13324

Требуется JDK 17 или новее. Внешние библиотеки не нужны.

БЫСТРЫЙ ЗАПУСК
  java -jar lab3.jar

СБОРКА И ТЕСТЫ
  Windows PowerShell:  .\build.ps1
  helios / Linux:      sh build.sh

ПРИМЕРЫ
  java -jar lab3.jar --seed=42
  java -jar lab3.jar --rum=5
  java -jar lab3.jar --capacity=1
  java -jar lab3.jar --friday-energy=0
  java -jar lab3.jar --dark --rum=0 --father-energy=0
  java -jar lab3.jar --rum=-1
  java -jar lab3.jar --help

Параметры задаются через знак =. Базовое зерно случайности — 13324.
Одинаковые параметры дают одинаковый журнал. Другой seed меняет реакции.
Неверные параметры завершают программу с кодом 2, штатный сценарий — с кодом 0.
